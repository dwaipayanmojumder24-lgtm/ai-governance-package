# Sample AI Project: Customer Support Assistant

This is an example AI application provided for testing the **Enterprise AI Governance Package**.

## What this application does:
- Handles customer queries using a simulated LLM (`openai`).
- Uses a local vector database for knowledge retrieval (`chromadb`).
- Processes customer personal data (`customer_email`).
